# Claude Code instructions

## Git commits and attribution

Never add AI attribution to any commit or push. This means:
- Do NOT add "Co-authored-by" lines of any kind
- Do NOT add "Generated by", "Created by AI", or similar lines
- Do NOT modify git `user.name` or `user.email`
- Leave commit authorship exactly as the local git config has it

This rule applies to every commit in this repo, no exceptions.
